C++

Mijn eerste C++-opdracht: meer werk dan ik dacht

25 september 2023 · C++ · 5 min lezen

Mijn eerste Programmeermethoden-opdracht leek op het eerste gezicht niet heel groot. Toch merkte ik tijdens het maken hoeveel verschillende onderdelen erbij komen kijken wanneer je een programma vanaf nul opbouwt.

In het begin was vooral het begrijpen van de basis belangrijk. Ik moest leren hoe variabelen, voorwaarden en lussen werken en hoe deze onderdelen samen een programma vormen. Een klein foutje in de logica kon er al voor zorgen dat het programma niet deed wat ik verwachtte.

Wat ik vooral heb geleerd, is dat programmeren niet alleen gaat over code schrijven. Het gaat ook over nadenken over het probleem en het stap voor stap oplossen daarvan. Door mijn code steeds opnieuw te testen, kreeg ik beter inzicht in waar fouten vandaan kwamen.

Wat ik leerde van coderen, decoderen en het Collatz-vermoeden

11 december 2023 · C++ · 6 min lezen

In een volgende opdracht werd het programmeren wat uitgebreider. Ik werkte met bestanden en moest gegevens uit een bestand verwerken. Daarnaast kwam het coderen en decoderen van informatie aan bod.

Een onderdeel van de opdracht was het toepassen van het Collatz-vermoeden. Hierbij moest ik voor verschillende getallen berekeningen uitvoeren totdat aan een bepaalde voorwaarde werd voldaan. Hierdoor oefende ik niet alleen met C++, maar ook met het vertalen van een probleem naar stappen die een computer kan uitvoeren.

Ik merkte hierbij dat het belangrijk is om eerst goed te begrijpen wat een opdracht precies vraagt voordat ik begin met programmeren. Wanneer ik meteen code ging schrijven, liep ik sneller vast. Door eerst het probleem op te delen werd het makkelijker om de code overzichtelijk te houden.

C++

Van programmeren naar een compleet spel

Programmeermethoden · C++ · Projectervaring

Tijdens Programmeermethoden heb ik samen met Joelle Tiao gewerkt aan verschillende spelprojecten in C++. Twee voorbeelden hiervan zijn Nonogram en Gomoku.

Bij Nonogram werkte ik aan een logisch puzzelspel waarin de speler door een puzzel kan bewegen en vakken kan aanpassen. Hierbij kwamen onder andere classes en arrays aan bod.

Bij Gomoku werd het project uitgebreider. Het spel ondersteunt speler tegen speler, speler tegen computer en computer tegen computer. Hierdoor moest niet alleen het bord worden bijgehouden, maar moest ook worden nagedacht over verschillende manieren waarop spelers een zet kunnen maken.

Door deze projecten kreeg ik beter inzicht in hoe losse stukjes code uiteindelijk samen een groter programma vormen. Vooral het werken met classes en het overzichtelijk verdelen van verantwoordelijkheden vond ik hierbij interessant.

Van een breed idee naar EcoNect

4 september 2025 · Challenge · 5 min lezen

Tijdens een challenge begonnen we met een vrij breed idee rondom voedselverspilling. Tijdens het onderzoeken en het krijgen van feedback kwamen we erachter dat hier al veel bestaande oplossingen voor waren.

Daarom zijn we opnieuw gaan kijken naar het probleem dat we wilden oplossen. Uiteindelijk kwamen we uit bij EcoNect en het binnenklimaat van scholen.

Ik vond vooral het proces van een breed probleem naar een concreter concept interessant. Het maakte duidelijk dat een technisch project niet alleen draait om programmeren, maar ook om het begrijpen van het probleem en de gebruiker.

Wat ik leerde van een project waarin alles samenkomt

15 januari 2026 · Challenge · 7 min lezen

In het tweede deel van de challenge kwamen verschillende onderdelen van ICT samen. We werkten onder andere met embedded systems, databases, programming en security.

Hierdoor kreeg ik een beter beeld van hoe verschillende ICT-onderdelen elkaar kunnen aanvullen. Een applicatie bestaat niet alleen uit de code die een gebruiker ziet. Ook gegevensopslag, hardware en beveiliging kunnen onderdeel zijn van hetzelfde project.

Ik merkte hierdoor dat het handig is om niet alleen naar één onderdeel van een project te kijken. Een keuze in de programmering kan bijvoorbeeld invloed hebben op de database of op de manier waarop gegevens worden beveiligd.

Deze ervaring heeft mij geholpen om ICT meer als één geheel te zien in plaats van als losse vakken.

Java

Van losse onderdelen naar een echte hotelsimulatie

13 september 2026 · Java · 6 min lezen

Bij de Hotel Simulator werk ik aan een groter Java-project waarin meerdere onderdelen tegelijk moeten samenwerken. Het doel is om gebeurtenissen in een hotel te simuleren en deze gebeurtenissen zichtbaar te maken in een applicatie.

Tijdens dit project werk ik met Java Swing voor de grafische interface. Daarnaast gebruik ik het MVC-model om het project op te delen in verschillende onderdelen. Hierdoor staat de gebruikersinterface niet volledig los van de logica, maar hebben de verschillende onderdelen ieder hun eigen verantwoordelijkheid.

Een belangrijk onderdeel van de simulator is het werken met events. Bijvoorbeeld wanneer er een brandalarm afgaat of wanneer gasten door het hotel moeten worden verplaatst. Hiervoor wordt gewerkt met een HotelEventManager en listeners.

Dit project is voor mij een stuk groter dan de eerdere programmeeropdrachten. Daardoor leer ik vooral hoe belangrijk structuur wordt wanneer een programma steeds meer onderdelen krijgt. Als alles in één klasse zou staan, zou het snel onoverzichtelijk worden.

Ik ben hierdoor steeds meer gaan letten op hoe ik mijn code opbouw, hoe klassen met elkaar samenwerken en hoe ik onderdelen afzonderlijk kan testen.

Wat ik tot nu toe heb geleerd over samenwerken

HBO-ICT · Projectervaring

Naast programmeren heb ik tijdens mijn opleiding ook geleerd dat samenwerken een groot onderdeel van ICT is. Bij groepsprojecten moeten taken worden verdeeld en moet duidelijk zijn wie waarvoor verantwoordelijk is.

Tijdens projecten heb ik gemerkt dat goede communicatie veel problemen kan voorkomen. Wanneer iedereen weet wat er moet gebeuren, wordt het makkelijker om vooruitgang te boeken en elkaar te helpen wanneer iemand vastloopt.

Ik probeer daarom niet alleen te kijken naar mijn eigen onderdeel, maar ook naar hoe mijn werk aansluit op dat van anderen. Vooral bij grotere projecten is het belangrijk dat verschillende onderdelen uiteindelijk goed met elkaar kunnen samenwerken.
